## 📌 Overview

LifeDraft AI is an AI-assisted web application designed to simplify complex decision-making.

Instead of simply recommending an option, the application guides users through a structured decision process by evaluating multiple perspectives, identifying trade-offs, and predicting potential outcomes.

Whether deciding on a career path, education, finances, or personal goals, LifeDraft AI provides intelligent, context-aware assistance powered by Google's Gemini API.

---

## ✨ Features

- 🧠 AI-powered decision analysis using Gemini API
- 📊 Multi-step decision workflow
- 🔮 Future outcome simulation
- ⚖️ Pros & Cons comparison
- 🎯 Value and priority alignment
- 📈 Interactive data visualization with Recharts
- 💬 Natural language interaction
- 🎨 Clean and responsive user interface

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm
- Gemini API Key

---

### Installation

Clone the repository

```bash
git clone https://github.com/Khushii-exe/my-gemini3-app.git
```

Move into the project directory

```bash
cd my-gemini3-app
```

Install dependencies

```bash
npm install
```

Create a `.env.local` file

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Start the development server

```bash
npm run dev
```
